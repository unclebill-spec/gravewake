# wow SFX loudness check (gw-left-1117, 2026-11-17, Master Builder)

Open item: "wow SFX ~7 dB hot (~-18.7 vs ~-26 LUFS)". That figure compared the wow FILES (about -18.6 LUFS integrated, as Sound's README says)
with quieter ambience levels; it did not include the in-game gains. In game a wow one-shot plays at `sfx x WOW_SFX[k].vol x WOW_TRIM (0.5)`
and a jsfxr SFX at `sfx x SFX_TRIM[name]` (src/game/audio.ts), both into the same compressor.

Measured with ffmpeg ebur128 (integrated LUFS, 1 s silence padding each side, mono 44.1 kHz) on the file times its in-game gain:
`qa/wow/lufs_1117.sh <file.ogg> <gain>`.

- Other SFX (17 cues, file x SFX_TRIM): median -24.4 LUFS, mean -24.0, range -29.4 to -18.3.
- wow one-shots (14 cues, file x vol x 0.5): median -26.3 LUFS, mean -27.3, range -36.3 to -23.8.
- wow loops/idle (wisp-twinkle, trophy-shimmer) sit lower by design (Sound's -28 LUFS files).

Result: in game the wow one-shots are already in line with the other SFX (median about 2 dB quieter, inside the SFX range), because
WOW_TRIM 0.5 (-6 dB) was added on 2026-10-22. Raw files ~-18.6 vs effective ~-24 to -29. No gain change made: lowering them further
would push them below the rest of the SFX. Before = after (no audio or gain change in this branch).
