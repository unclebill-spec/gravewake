================================================================
SCREEN MAP
================================================================
- Portrait flush to left bezel (top-left). Flickers during i-frames.
- Pause under the portrait. HOLD 0.35s to confirm (cheek-press guard).
- Vitals right of portrait: LV, XP current/next, HP bar (hatch fill, not hue-only),
  mana/stamina bar. Vampire: drop mana/stamina, show Blood only.
- Day/Night chip BETWEEN bars and minimap. Shared clock cycleT 0..1.
  Moon cover = abs(cycleT - 0.5) * 2. Weather tag under chip (WX).
- Minimap top-right. Drag to move. Double-tap or pinch collapses to a 24px pip.
  Fog unexplored. Player arrow only. No quest spam.
- Playfield: shader grade + weather particles under HUD.
- Right rail: max 4 visible slots (orb, ring, then spells). Empty slots HIDDEN.
  Long-press to remap. Combat cannot open the pack. Overflow lives in Pause.
- Lower left: on-screen joystick.
- Lower right: two mediums (SEC, 3RD) + large MAIN below/between them + two potion pills
  (old Start/Select) = HP pot / mana-or-blood pot.

Left-hand flip: swap stick cluster with MAIN cluster. Rail stays on the outer thumb edge
(right for right-hand, left for left-hand).

Every other preset keeps the C10 view exactly. ================================================================
1. MAIN VERB + HOLD
================================================================
MAIN shows one glyph for the current verb:
  sword   foe in range
  talk    NPC
  hoe     farm plot
  door    threshold
  hand    loot / chest / cairn
Tap MAIN = do that verb. In a fight the verb is sword and tap also fires the main attack.
Hold MAIN 0.35s = interact-only (talk / open / till). Never swings into Rook.
No foe and no context = tap does nothing (no dirt-swing).

================================================================
2. HIT FEEDBACK
================================================================
On connect: 1-frame white flash on the struck sprite, 2–3 px knockback on the pixel grid.
Screen shake only on crit, warden, Fourfold, Sovereign, or vampire.
No bloom. i-frames (Morrowstead 0.7s or title equivalent): portrait flickers.
Do not add extra HUD hit meters.

================================================================
3. POTION PILLS
================================================================
HP pot / mana pot (blood pot if vampire — never show a blue flask in vampire form).
Empty = greyed, tap ignored. Hold 0.25s to chug (fat-finger guard).
Cannot drink during the coffin / death toast.

================================================================
4. STICK
================================================================
Deadzone 12–15%.
Marrowstead 16-bit: snap to 8 directions.
Morrowstead 2.5D / 32-bit: free analog.
Outer ring of the stick = sprint / run (no fourth face button).
Pixel-perfect draw positions at native res (Layout One does not change that law).

================================================================
5. SOFT-LOCK
================================================================
No hard target button. MAIN favors the nearest foe in a 40° cone in front of facing.
Cone lost = next nearest in cone, else context verb, else nothing.
Does not steal facing from the stick.

================================================================
6. RAIL DISCIPLINE
================================================================
Visible cap 4. Hidden empties. Long-press remap. No pack in combat.
Rail is triggerable gear-spells only (orb, ring, inscribed items). Not weather. Not pots.

================================================================
7. MINIMAP
================================================================
Draggable. Collapse to 24px pip (double-tap / pinch). Fog of war. Player arrow only.

================================================================
8. DAMAGE NUMBERS
================================================================
One floating integer, native pixel font, nearest-neighbor scale.
Crit = same font, +2 px. No rainbow, no miss spam.
Optional off in Pause. Skip chip-damage numbers if the 16-bit field is already busy.

================================================================
9. DEATH / CAMP  (per-game, not unified)
================================================================
Layout One only draws: pause-tint + short toast.
Morrowstead toast: "You drop. The ash is patient." Continue from last save.
Marrowstead toast: "The coffin shuts. You gather in the crypt." −8 gold, full HP, Home Crypt.
Camp / sleep stays in each game bible. Cannot camp under attack (Marrowstead).
Do not merge those rules.

================================================================
10. ACCESSIBILITY
================================================================
- Left-hand flip (stick <-> action cluster).
- HP bar uses hatch + width, not color alone.
- Pause requires 0.35s hold.
- Potion chug requires 0.25s hold.
- Damage numbers toggle in Pause.

================================================================
FX RULE  (particles + shaders — standing law)
================================================================
This rule binds the optimization notes and shader-graph workflow.
Detail lives in GAME_LAYOUT_ONE_FX_PIPELINE.txt.

PARTICLES
- After world grade, before HUD. Never on stick, MAIN, rail, or panels.
- Detail in the texture, not the count. Whirl = dust-ring quad, not 40 specks.
- Pool every burst. SoA typed arrays (x,y,vx,life,hue). No new/destroy per Slash.
- One instanced draw for all 2×2 chips. Wastes ash = scroll tile when cheaper.
- Caps: weather per title (Gravewake ash 40–80 wastes, 8–12 hub, mute in delves);
  combat 24; interact 16; hub ambient 12. Over cap = oldest dies.
- Opaque / alpha-cut chips. No big additive clouds.
- Damage numbers = 0–9 sprite strip in the same pool. No text meshes.
- Offscreen or fogged = don't spawn. If frame spikes: cut weather first, never Slash chips.

SHADERS
- Unlit particle path. Vertex color = lifetime + tint. One atlas sample (two max).
- Pack ash/spark/ring/numbers into RGBA of one atlas.
- Four programs only: WorldGrade (cycleT + weather mul), ChipParticle, AshTile,
  LightBlob (nearest). No bloom, TAA, PBR-per-chip, or extra lighting model.
  [OWNER-APPROVED 2026-10-01: CORE KEEPER GRAPHICS PASS C1-C11] C6: the light-buffer composite (an extended LightBlob, Canvas2D multiply, no shader) is allowed. Still no bloom.
- Web Gravewake: GLSL/WGSL, not a Unity graph at runtime. Shader Graph is the
  authoring pattern if the title later moves engines (URP Unlit Particle + instancing).

ASHFIELD COMBAT LAW
================================================================

GAME LAYOUT ONE — GRAVEWAKE COMBAT OPTION
"Ashfield"  — real-time Diablo-3 open-world combat
Replaces any turn-based / menu-fight layer. Same pad. Same field.
Updated 30 September 2026

================================================================
LAW
================================================================
No second battle screen. Fights happen on the Wastes and in delves.
Player verbs stay Layout One: MAIN Slash, hold Interact, SEC Whirl, 3RD Smite.
Soft-lock 40° cone. i-frames + 1-frame flash + 2–3 px knockback already in Layout One.
Death: fallen overlay, reload run0. No gold tax.

Threat is a pack problem, not a menu problem. You kite, interrupt, or die.

================================================================
PLAYER (unchanged verbs, real-time timing)
================================================================
Slash     MAIN     melee cone, no resource
Whirl     SEC      18 stam, spin, hits around feet
Smite     3RD      12 mana, bolt, interrupt-tag on telegraphed boss casts
Potion    hold     0.25s chug, grey when empty
Run       stick outer ring

Stam / mana regen only out of hit-stun. Cannot drink during fallen overlay.

================================================================
MONSTER TIERS
================================================================
Trash     1 signature move + idle walk. Telegraphs never.
Rare      1 pack affix + 1 personal trick. Short tell (0.35s).
          [OWNER-APPROVED EXCEPTION 2026-09-30: MIMIC] Mimic: no pack affix; the trick is one bite lunge.
Mini      2 abilities, one is a gap-closer or summon. 0.5s tell.
Boss      3–5 abilities on a cycle. Big move always telegraphs 0.8–1.2s
          with a ground decal + portrait pulse (not a HUD sparkle).

All four tiers have a PERSONALITY (below). Personality picks which ability
fires, not a random table.

================================================================
PERSONALITIES
================================================================
One word. Drives spacing and which ability they spend first.

Brawler     walks into Slash range, swings, rarely flees
Kiter       keeps 6–8 units, tosses, runs when you Whirl
Anchor      plants, slams, summons; you must come to it
Skirmisher  dash in, 2 hits, dash out
Coward      fights only in a pack; flees at 30% if alone
Zealot      ignores kiting, walks through Whirl, dies loud
Warden      faces the player, holds a lane, big-move on a clock
Tyrant      summons, links adds, big-move when bloodied (<40%)

Trash gets Brawler / Kiter / Coward.
Rare gets Skirmisher / Zealot + one affix.
[OWNER-APPROVED EXCEPTION 2026-09-30: MIMIC] The mimic is a Skirmisher with no affix.
Mini gets Anchor or Skirmisher.
Bosses are named: Bellwarden = Warden, Death Knight = Skirmisher,
Bone Tyrant = Tyrant.

================================================================
TRASH MOVES  (one each)
================================================================
Ash walker      swipe
Bone rattler    bone toss (kiter)
Grave hound     lunge (skirmisher-lite)
Ashkite         peck + hop
Bell thrall     slow smash (brawler)

Never more. Personality is the variety, not a 12-move kit.

================================================================
RARE / CHAMPION PACKS  (Diablo "linked")
================================================================
A rare is a pack: 1 rare + 2–4 minions.
[OWNER-APPROVED EXCEPTION 2026-09-30: MIMIC] The mimic is the ONE solo rare: 1 rare, no minions, no pack affix. Its personal trick is one bite lunge on the existing 0.35s rare tint (the existing "line" shape, 18 px mark: OWNER-APPROVED COMBAT CHANGE 2026-09-30 10:35 PM ET, so a sidestep beats it; no new hit shape). Skirmisher. Stats on the one curve (scaleMonster), Stalker numbers: L+2, HP*1.45. Every other rare is still a pack. The check suite enforces that only the mimic builds solo.

AFFIXES (pick 1, never stack 3 on open-world trash):
  Linked     shared HP pool on the minions; rare has its own bar.
             Kill the rare OR drain the shared pool. Minions freeze-pose
             when the pool hits 0.
  Chained    2 rares tied together; damage splits 50/50 until one drops,
             then the survivor enrages (+20% speed, lose the link).
  Horde      rare summons 2 trash every 8s, cap 6 live.
  Vortex     pulls 4 units once per 10s, 0.35s tell.
  Mortar     arc shot at last stand position, 0.5s ground mark.
  Fast       +25% move, no extra HP.
  Shielded   first 20% HP is a breakable shell; Smite shatters it faster.

Open world: one rare pack on screen at a time unless a delve script says else.
Linked is the default "Diablo share a pool" read. Chained is the fancy one;
use it on mini-boss intros, not every Wastes pack.

================================================================
MINI-BOSSES
================================================================
Two abilities + personality + optional Horde.
Examples:
  Bell-captain     slam (0.5s ring) + whistle (summon 2 thralls)
  Catacomb knight  dash-stab + frost cone (0.5s)
  Keep butcher     hook (gap close) + cleave

HP about 6–8 trash packs. No enrage timer. If you leave the arena, they leash
and reset HP — D3 pack leash, not a raid wipe.

================================================================
BOSSES  (milestone rooms)
================================================================
Always: 3–5 abilities, one SUMMON, one BIG (telegraphed), one SPAM.
Big move: ground decal + boss flash + optional bell/howl sting. You can walk
out. Smite on the flash interrupts the BIG once per phase (then locked 12s).

BELLWARDEN  (Warden)
  spam    clapper swipe
  mid     toll — 0.8s ring expanding, stand inside or outside (alternates)
  big     peal — full-room shock, 1.2s floor runes, interruptible
  summon  3 bell thralls at 70% and 35%, cap 3

DEATH KNIGHT  (Skirmisher)
  spam    frost cut
  mid     blink-stab behind the player
  big     grave-vow — 1.0s cross on the floor, two slashes
  summon  2 grave hounds once per phase, cap 2

BONE TYRANT  (Tyrant)
  spam    bone toss volley
  mid     linked cage — two bone pillars, SHARED HP, must break one
  big     throne-fall — 1.2s collapse circle under the player
  summon  4 rattlers at 60% and 25%, and they are LINKED to each other

Phases are HP gates, not timers. Leaving the room resets the fight.
Packs outside the room stay asleep until you exit.

TELEGRAPHS
================================================================
Trash     none
Rare      0.35s tint on the actor
Mini      0.5s ground mark

================================================================
WEAKNESSES — VERDICT
================================================================
Do NOT ship hard immunities ("only weak to Smite / only fire").
Open-world ARPGs punish a 3-button kit when a pack is unkillable with Slash.
Players feel the build is broken, not clever. D3 itself uses RESIST slivers
and breakable shields, not "this skeleton ignores all physical."

USE INSTEAD
  Resist 30–50% to one damage family (slash / whirl-phys / smite-holy).
  Shielded affix (above) as the "bring Smite" tease.
  Bellwarden takes +25% from Smite on the BIG window only.
  Bone-family takes +20% from Whirl (cracks).
  Never 0% damage from a player verb.

If a later expansion wants a puzzle mob, make it a MINI with a breakable
shell, not a Wastes walker you cannot scratch.

================================================================
AGGRO / LEASH
================================================================
Trash aggro 8 units or on hit. Leash 18 units back to spawn, snap reset.
Rares leash 24. Bosses do not leash mid-phase; door seals until dead or you die.
No friendly fire on summons vs their boss.

================================================================
LOOT TIE-IN
================================================================
Trash: table 1. Rare: table 2 + chance at gem. Mini: table 2 guaranteed gem roll.
Boss: milestone table + one skill choice if pending. Combat option does not
invent new inventory rules.

================================================================
DO NOT
================================================================
Turn-based menus, ATB bars, action queues, "choose Smash / Guard / Item."
Hard immunities. Three affixes on one Wastes pack. Uninterruptible big moves
with no decal. Summon storms over cap 6. Particles over FX RULE caps.

================================================================
PARTICLE OPTIMIZATION
================================================================
Goal: stay inside Layout One caps (weather 80 ash, combat 24, interact 16, hub ambient 12)
on a phone, without GC hitch or HUD jank.

1. Detail in the texture, not the count
   One 8×8 chip with a good silhouette beats 20 dots.
   Whirl is a dust RING texture (1–2 quads), not 40 specks.
   PocketGamer midcore VFX: many effects drop from ~30 particles to 2–10
   by painting motion into the sprite. That is the Gravewake default.

2. Pool. Never new/destroy per Slash
   Preallocate the cap. On emit: reset position/life/color. On death: return to pool.
   Web/JS: typed arrays (SoA) — x[], y[], vx[], life[], hue[].
   AoS objects per chip will GC stutter on Android.

3. One draw
   All combat chips share one atlas + one instanced draw (ANGLE_instanced_arrays / WebGL2).
   Weather ash is a scrolling fullscreen tile (already Layout One backend 2), not 80 sprites
   if fill-rate allows a 64px tile instead.

4. Simulate cheap
   Integrate on GPU only if WebGL2 + headroom. Else CPU on the SoA in one tight loop.
   No per-particle collision. No noise texture sample per chip.

5. LOD / distance
   Offscreen = dead. Behind fog in delves = don't spawn. Hub crafts don't run in Wastes.

6. Overdraw
   Additive is expensive on mobile fill-rate. Gravewake chips are opaque 2×2 or alpha-cut,
   not big soft additive clouds. Soft fog cards stay at 12–24 and only in Wastes edges.

7. Damage numbers
   Do not spawn a text mesh per hit (DRG Survivor lesson). Use a 0–9 sprite strip in the
   same particle pool. Layout One already wants one native pixel integer.

8. Budget check
   If frame time spikes on a pack + Whirl + ash: cut weather first, then interact glints,
   never the Slash chips (readability).

================================================================
SHADER GRAPH WORKFLOWS
================================================================
Gravewake ships on web (Vite / Anvil / WebGL). Unity Shader Graph and Unreal Material
Editor are the *authoring pattern*, not the runtime unless the title moves engines.

Workflow to steal from Shader Graph (Unity 6 / URP):
- Start from an UNLIT particle template, not Lit PBR.
- Vertex color = lifetime + tint (Layout One cycleT and weapon hue ride this).
- Flipbook / atlas UV in the graph, one texture sample. Two samples max on mobile.
- Pack masks into RGBA of that one atlas (ash / spark / ring / number strip).
- Custom lighting, if any, is the cycleT grade already in Layout One — do it as a
  multiply on the backbuffer or a hemisphere uniform, not per-particle PBR.
- No bloom node. No TAA. No soft-particle depth fade unless delves need it later.

Recommended graphs to keep (even if written as GLSL/WGSL):
A) WorldGrade     inputs: cycleT, weather mul    output: scene tint + fog
B) ChipParticle   inputs: atlas, vertex color, instance pos
C) AshTile        inputs: scroll UV, density     Wastes only
D) LightBlob      2-frame off-hand / shrine glow, nearest filter

Authoring loop
1. Block the effect as 1–2 texels on paper (Layout One law).
2. Paint the atlas cell.
3. Wire Unlit graph or GLSL with vertex color lifetime.
4. Cap emitter to the table in GRAVEWAKE particles.
5. Profile overdraw (flash tint) before adding a second sample.

If a future title is Unity: use URP Unlit Particle target + GPU instancing on the
Renderer module; Custom Lighting sample for the cycleT sun, not HDRP.

If Godot: VisualShader on particles, filter = nearest, process_material with
preallocated amount = cap.

Web Gravewake now: skip a visual editor; keep two GLSL programs (grade + chips)
and one atlas. That is the shader-graph workflow with the nodes collapsed.
